# DiPlay for Starwish

吉利星愿无线 CarPlay 静默连接实验版。使用 [公开 APK](experimental/silent/DiPlay-Starwish.apk) 或查看[星愿适配补丁](experimental/silent/source.patch)。公开 APK 不含个人配件认证材料。

在 GitHub Actions 中手动运行 [Starwish silent wireless experiment](.github/workflows/starwish-silent.yml) 可重新构建。工作流检出指定版本的 DiPlay，应用补丁并生成调试 APK。
